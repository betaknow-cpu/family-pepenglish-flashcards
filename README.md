# 小学英语闪卡（PEP 三 / 四 / 五年级）

一套给小学生用的英语练习网页。**下载后双击就能用**——不用装软件、不用联网、不用搭服务器。单词、短语、句子按 PEP 课本整理。

## 能做什么

- **翻卡记忆**：正面英文 + 音标，翻面看例句和中文
- **听写**：写错进生词本，累计写对 2 次移出
- **句子练习**：听写 / 拼图两种玩法，答完逐词音标 + 成分着色 + 中文
- **错题集**：写错自动收进来，同一种练法连对 3 次才移出
- **单元筛选**：按上下册单元练，英式发音（en-GB）

## 怎么用

1. 点 **Code → Download ZIP** 下载，解压到一个文件夹
2. 双击 **`index.html`** → 选年级 → 开始
3. 也可以直接双击某个年级的 HTML

**注意：3 个 `.js` 文件和 HTML 必须放在同一目录**，缺一个就打不开。

## 关于数据

- 词表、例句、句子**全部来自课本**，不编造课本外内容
- 进度存在**当前浏览器**里，不上传、不跨设备同步；清理浏览器数据会丢失
- 发音用浏览器内置英式语音；没声音就换 Chrome / Edge，或装英语语音包
